 # Dirac-to-C ⚛️

Este repositório documenta meu caminho testando sugestões na Computação Quântica, 
partindo do teste  no teórico até a prática.
Não é nada muito refinado,mas uma base para entender.

## 🚀 O que tem aqui:
- Simulação de qubits e estados de superposição.
- Implementação manual de portas quânticas (Hadamard, Pauli-X, CNOT).
- Produto de Kronecker para sistemas multi-qubit.

## 🛠️ Tecnologias:
- **Octave**: Para verificação de certos resultados.
- **C**: Para construção da simulação base.
- **Python**:Para fazer gráficos e transformar os dados em imagens.

> **Nota:** Se o Python der erro de `file not found`, é só conferir se o terminal está na pasta certa ou se o ficheiro foi parar à pasta `output`.

---
*Esse repositório é voltado mais para testes de ideias, por isso o código pode parece "mal feito", mas a ideia é entender e quem sabe me aprofundar!* 🧪
